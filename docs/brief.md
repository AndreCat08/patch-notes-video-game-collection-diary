# Patch Notes: Video Game Collection Diary
Build a single-page app where gamers can catalog their personal video game collection — physical and digital — and track the status of each title.

Each game entry should include: title, platform (e.g. Switch, PS5, PC), format (physical/digital), current status (Not Started / In Progress / Completed / Dropped), and an optional short personal note (e.g. "stuck on the final boss").

The app should display all games in a scrollable card list. Users can add new games via a form, edit existing entries, and delete ones they no longer own. A simple summary bar at the top should show counts by status so the user can see at a glance how many games they've completed versus haven't started.

All data must persist using localStorage so the collection survives a page refresh. No backend, no login — just a clean, usable personal catalog that a gamer would actually want to open every day.
